# BAR Controller Support v0.8.5 Experimental

Install with `BAR_Controller_Companion_Installer_v0.8.5_Experimental.exe` from the extracted package. The installer consumes `controller-release-manifest.json`, validates every component, creates a recovery backup, preserves user configuration, and never launches or terminates BAR.

This release restores `RB+X` general front insertion, keeps factory/build front insertion on `RB+A`, adds factory Queue/Quota Mode presentation, and adds `RB+D-pad` mobile type navigation.

Use `Install_v0.8.5.ps1` for scripted installation from an extracted package. Recovery Mode and the updater should still expose earlier public releases, including v0.8.4.
