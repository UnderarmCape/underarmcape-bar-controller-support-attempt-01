# BAR Controller Support v0.8.5

Release tag: `controller-support-v0.8.5-unit-insert-quota-type-navigation`

Package: `BAR_Controller_Support_v0.8.5_UNIT_INSERT_QUOTA_TYPE_NAVIGATION.zip`

## Highlights

- Restores general front insertion on `RB+X` while preserving build/factory insertion on `RB+A`.
- Consumes protected RB chords so build radials and tactical replay cannot leak after `RB+X`, `RB+D-pad`, or `RT+RB`.
- Adds factory Queue/Quota Mode presentation with exact toasts, magenta center/`X/Y` quota counts, construction progress wipe, and immediate queue-count refresh after insert.
- Adds `RB+D-pad Left/Right` mobile type cycling and `RB+D-pad Down` visible same-type selection.
- Tightens idle cycling, Disassemble eligibility, same-type reclaim radius defaults, and contextual hints.
