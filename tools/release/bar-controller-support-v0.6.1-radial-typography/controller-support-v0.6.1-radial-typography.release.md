# BAR Controller Support v0.6.1 — Radial Typography & Color Controls

A public radial typography and color-authoring update for BAR Controller Support.

This is the recommended stable public release.

## Highlights

- Independent radial category-label, center-title, and center-description sizing and color.
- Independent metal and energy cost typography, icon sizing, and spacing; energy ships as readable yellow.
- Metadata, footer, page, slot-number, unavailable, and selected-state roles.
- Global radial styles plus explicit Build, Factory, Tactical, Selection, and Visible Selection Filter overrides.
- Compact HSV/alpha gradients, exact fields, 20 named swatches, copy/paste, favorites, and recents.
- Production-renderer previews and deterministic 30/30 property-wiring coverage.
- All v0.6.0 behavior: polished UI authoring, hint stabilization, corrected LB tactical layer, LB+LT visible-selection filter, Combat default, and Last Selected.

## Installation

1. Download `BAR_Controller_Support_v0.6.1_Widget_Companion.zip` and its `.sha256` sidecar.
2. Verify and extract the ZIP.
3. Run `BAR_Controller_Companion_Installer_v0.6.1.exe`.
4. Launch BAR using the normal patched Desktop or Start Menu shortcut.

SmartScreen may warn because the executables are unsigned. No custom Recoil engine is required.

Upgrading preserves controller bindings, personal radial layouts, custom colors, favorites, themes, presets, and profiles. Restore with `BAR_Controller_Companion_Restore_v0.6.1.exe`.
