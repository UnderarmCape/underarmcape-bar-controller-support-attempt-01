# Recovery Mode

Run `BARControllerBridge.exe recover` or choose R from the update prompt. The 68-column keyboard browser paginates compatible public releases, shows date/title/tag details, and marks `[Installed]`, `[Latest]`, `[Prerelease]`, `[Legacy]`, and `[Unavailable]` in text as well as color.

The floor is verified v0.6.0; older releases are hidden. Update, downgrade, and reinstall use the same verified transaction and require confirmation for downgrade/reinstall. Backups are never deleted automatically. Legacy adapters switch exact verified LuaUI payloads while preserving the modern recovery companion and configuration.
