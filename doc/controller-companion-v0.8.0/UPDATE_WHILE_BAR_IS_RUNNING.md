# Updating while BAR is running

BAR/Spring/Recoil is detected but never terminated or awaited. Writable LuaUI/native-override files install immediately after full validation and backup. After success the helper prominently instructs the user to enter `/luaui reset`; it never sends the command automatically.

The warning explains that active controller state may reset and that non-Lua engine-level content can still require an engine restart when native overrides change. Companion locks are handled by the external updater after only the companion exits. All configured/user-created data remains preserved by manifest rules.
