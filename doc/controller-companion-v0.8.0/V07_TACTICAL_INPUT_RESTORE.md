# v0.7 tactical input restoration

The restoration retains the v0.7 controller contract while using current BAR descriptors and native finalizers. LB+ABXY point shortcuts call the Order Menu immediate-at-cursor adapter once and do not enter an anchored mouse gesture.

Choosing a point command in the Tactical Radial closes the radial, captures the descriptor, clears the engine mouse owner, and waits for A and X to become neutral. The next fresh A or X places at the current controller cursor; B cancels. The radial-selection edge never creates an anchor.

Area, front, and rectangle commands share `controller_native_targeting.lua`: fresh A/X stores the first point, release arms adjustment, cursor motion updates geometry, and another fresh A/X confirms. Release cannot confirm. This is the selective behavioral restoration of the v0.7 staged target functions; old command models and obsolete direct dispatch branches were not revived.
