# Disassemble Chords

Disassemble mode priority in v0.8.3 is:

1. L3+R3 clears the selected reclaim queue and stays in Disassemble.
2. LB+B issues Stop and stays in Disassemble.
3. LB+A tap issues one reclaim.
4. LB+A hold starts same-type radius reclaim.
5. X handles target, ground, and hold path behavior.
6. B clears the current target, and double-B exits the mode.

Self Destruct never owns plain L3+R3. It requires the protected Tactical arm flow plus Back/View+L3+R3.
