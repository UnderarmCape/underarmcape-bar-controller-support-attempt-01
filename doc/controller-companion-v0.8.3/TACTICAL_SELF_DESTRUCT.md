# Tactical Self Destruct

Self Destruct remains a protected Tactical action.

- The Tactical item uses the shared Tactical renderer with danger coloring.
- Selecting it arms the protected flow; it does not immediately issue the destructive command.
- Completion requires holding Back/View+L3+R3 for the configured hold duration.
- B/cancel while armed cancels the protected flow.
- Plain L3+R3 outside the armed flow remains available for Clear Queue.

Manual check: open Tactical, arm Self Destruct, cancel it with B, then arm again and verify the hold prompt requires Back/View+L3+R3.
