# v0.6.1 package inventory

The package contains four frozen win-x64 self-contained executables:

- `companion/BARControllerBridge.exe`
- `companion/BARControllerLauncher.exe`
- `BAR_Controller_Companion_Installer_v0.6.1.exe`
- `BAR_Controller_Companion_Restore_v0.6.1.exe`

It also contains the required controller Lua widgets and Include modules, controller glyph atlas/manifest/license, shipping defaults and manifest, runtime configuration templates generated by the installer, documentation, `LICENSE.md`, `manifest.json`, `frozen-runtime-manifest.json`, and `payload-sha256.json`.

It deliberately excludes the developer defaults publisher, credentials, tests, test output, build diagnostics, backups, personal settings, profiles, drafts, logs, private paths, source-control metadata, and temporary build directories.
