# v0.7.0 package inventory

The archive contains four hash-frozen, self-contained win-x64 executables: the bridge, launcher, v0.7.0 installer, and v0.7.0 restore tool.

Gameplay payload includes the camera, bindings, and lean runtime widgets; Disassemble behavior and runtime settings Include modules; shared radial/glyph renderers; and existing support widgets. The Controller UI Layout widget and its editor modules remain packaged only for optional F11 authoring.

Assets include the controller glyph atlas and dedicated metal, energy, and health icons, with manifests and license notices. Shipping defaults, defaults manifest, package manifest, frozen-runtime manifest, payload hashes, root license, and install/upgrade/restore documentation are included.

The archive excludes the developer defaults publisher, credentials, tests, output, deployment backups, personal settings, drafts, logs, private paths, source-control metadata, and temporary build files.
